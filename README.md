# 🐟 FishIt Clicker

## 🎯 Description
A Python script that automates **mouse click** and **mouse hold** actions for fishing in the **FishIt (Roblox)** game, making it easier to cast and catch fish perfectly.

## ✨ Features
- **Perfect Middle Mouse**  
  Click the **middle mouse button (scroll click)** to perform a *Perfect* cast automatically.
  
- **Auto Perfect (Press F)**  
  Press **F** to start *auto fishing* with *Perfect* casts every time.
  
- **Speed Clicking (Press J)**  
  While *auto fishing* is active in the game, press **J** to boost the catch speed.

## 🧩 Requirements
- Python **3.x**
- Package **pynput**

## 📦 Installation
Run the following command in your terminal:
```bash
pip install pynput
```

## ▶️ Usage
```bash
python main.py
```
